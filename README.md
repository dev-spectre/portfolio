# Portfolio

A personal portfolio website built with Next.js and TypeScript.

## Overview

A modern, interactive portfolio website featuring a terminal-style interface, skills showcase, work experience, and contact sections. Built with a unique developer-focused design.

## Features

- **Terminal-style UI** — interactive terminal theme
- **Skills showcase** — visual skills display
- **Work experience** — project and job history
- **Responsive design** — mobile and desktop friendly
- **Topbar/Navbar** — smooth navigation

## Tech Stack

- **Framework:** Next.js
- **Language:** TypeScript
- **Styling:** TailwindCSS, PostCSS
- **Components:** Custom UI components

## Getting Started

```bash
npm install
npm run dev
```
